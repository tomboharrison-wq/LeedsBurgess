Leeds Transect virtual fieldtrip (Year 8 Settlement, Lesson 3)

To host on Netlify: drag this whole folder onto https://app.netlify.com/drop
(or Sites > Add new site > Deploy manually). No build step is needed.

Stops can be opened directly with #stop1 to #stop5 on the end of the address.
